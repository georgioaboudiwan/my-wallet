## Google Play: Data safety answers

- Does the app collect or share user data? **Yes, collects.** Shared with third parties: **No** (Supabase and Groq are service providers acting for the app, which Play does not count as sharing).
- Is data encrypted in transit? **Yes.**
- Can users request deletion? **Yes** (in the app and at the delete-account URL).

| Data type | Collected | Purpose | Optional |
|---|---|---|---|
| Personal info: Email address | Yes | Account management | No |
| Personal info: Name (people you split with) | Yes | App functionality | Yes |
| Financial info: Other financial info (balances, entries, loans) | Yes | App functionality | No |
| Photos: receipt photos | Yes | App functionality | Yes |
| App activity: App interactions | Yes | Analytics | No |
| Device or other IDs: push notification token | Yes | App functionality (reminders) | Yes |

Not collected: location, contacts, health, messages, audio, files, web history, payment card details, advertising IDs.

## Android package (no coding needed)

1. Create a GitHub repository named exactly `georgioaboudiwan.github.io` (public). Add an empty file `.nojekyll` and a folder `.well-known`. Turn on GitHub Pages for it. This is where Android checks that the app and the website belong to you.
2. Go to https://www.pwabuilder.com, enter `https://georgioaboudiwan.github.io/my-wallet/`, then **Package for stores → Android → Google Play**.
3. Settings: Package ID `com.budgetsplit.app`, App name `BudgetSplit`, Launcher name `BudgetSplit`, Theme color `#0b3a2d`, Background `#edf2ee`, Signing key **Create new**. Fill in your name and country for the key.
4. Download the zip. Keep `signing.keystore` and `signing-key-info.txt` safe and private (a password manager or a private drive). Losing them means you can't update the app.
5. From the zip, copy `assetlinks.json` into the `.well-known` folder of the repository from step 1. Check it opens at https://georgioaboudiwan.github.io/.well-known/assetlinks.json
6. In Play Console ($25 once), create the app, fill the forms above, and upload the `.aab` file to **Testing → Closed testing**. Add 12 testers (their Gmail addresses), and keep the test running for 14 days. Then apply for production.
7. When Play Console shows the **App signing key** SHA-256 fingerprint (Setup → App signing), add it to `assetlinks.json` next to the one from PWABuilder, otherwise the app shows a browser bar.

## Apple App Store (later)

- Apple Developer Program: $99 per year.
- Wrap the app with Capacitor and add native parts so it isn't "just a website": Face ID for the app lock, native push notifications (APNs) for reminders, and optionally a home screen widget.
- App Privacy answers: same data as the Play table. Data linked to the user: email, financial info, user content (photos), usage data. Not used for tracking.
- If you add paid features, they must use Apple in-app purchase on iPhone.
- Sign in with Google or Microsoft on iPhone requires also offering Sign in with Apple.
