# Worksite — crew, days & pay

Track construction workers: weekly planner, days worked (full / half / hours), payments in USD or LBP, and what's left to pay per day, week or month. Arabic + English. Works on the web and installs to the phone home screen.

Data lives in the Money Inventory (Wallet) Supabase project, in its own `ws_*` tables. Same login as Wallet.

## Deploy
Served from the `my-wallet` repo's GitHub Pages at `/worksite/`. Push to `main` to update.

`schema.sql` is already applied; keep it for reference.
